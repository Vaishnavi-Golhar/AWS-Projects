# AWS Elastic Beanstalk Project

## 📄 Problem Statement
You work for **XYZ Corporation**. The organization is launching a **new web-based application**, but they want to avoid keeping servers running continuously. The application should be **fully managed by AWS** using a platform-as-a-service (PaaS) approach.

## ✅ Tasks To Be Performed
1. **Create an Elastic Beanstalk environment** with the runtime set to **PHP**.
2. **Upload a simple PHP file** to the environment once it is created.

## ⚙️ Tools & Services Used
- **AWS Elastic Beanstalk** – for application deployment and environment management
- **PHP** – as the application runtime
- **AWS Management Console** – for configuration and uploads

## 🧠 Learnings
- Understanding the basics of Elastic Beanstalk and its managed services
- Deploying PHP applications in a scalable and automated environment
- Using the AWS Console to manage application versions and environments
