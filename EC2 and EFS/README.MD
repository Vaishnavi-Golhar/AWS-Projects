# 📁 EC2 and EFS Project (Manual Setup using AWS Console)

This project demonstrates how to create an **Elastic File System (EFS)** and mount it to **three EC2 instances**, each running a **different operating system** — Ubuntu, Red Hat Linux, and Amazon Linux — all set up **manually via the AWS Management Console**.

---

## 📄 Project Report

The full step-by-step documentation (with screenshots) is included in the PDF:

## 📌 Key Highlights

- Launched EC2 instances with different OS (Ubuntu, RHEL, Amazon Linux)
- Created and configured an EFS
- Updated Security Groups to allow NFS traffic
- Installed NFS utilities and mounted the EFS on all 3 instances
- Verified shared storage using `df -hT`
- Documented with step-by-step instructions and screenshots
