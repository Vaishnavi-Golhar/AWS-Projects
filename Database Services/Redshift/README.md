# Redshift Assignment

## 📄 Problem Statement
You work for **XYZ Corporation**. Their application requires a database service that can store data which can be retrieved if required. Implement a suitable service for the same.

## ✅ Tasks To Be Performed
1. Create a **Redshift data warehouse**.
2. Using the **Query Editor**:
   - a. Load some sample data  
   - b. Run queries to fetch and analyze data  

## 📌 Tools & Services Used
- Amazon Redshift
- AWS Query Editor
- AWS Console

## 🧠 Learnings
- Working with Amazon Redshift (data warehousing solution)
- Creating clusters and managing access
- Loading and querying datasets using SQL
