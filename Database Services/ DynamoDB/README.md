# DynamoDB Project

## 📄 Problem Statement
You work for **XYZ Corporation**. Their application requires a database service that can store data which can be retrieved if required. Implement a suitable service for the same.

## ✅ Tasks To Be Performed
1. Create a **DynamoDB table** with **partition key as `ID`**.
2. Add **5 items** to the DynamoDB table.
3. **Take a backup** of the table.
4. **Delete the table** after backup is complete.

## 📌 Tools & Services Used
- AWS DynamoDB
- AWS Console / AWS CLI (for backup and deletion)

## 🧠 Learnings
- Hands-on with AWS DynamoDB
- How to define partition keys for NoSQL storage
- Backup and recovery process
- CRUD operations with DynamoDB
