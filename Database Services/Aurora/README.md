# 🌟 Amazon Aurora - RDS Assignment

This project demonstrates how to deploy an **AuroraDB Engine** using **Amazon RDS**, along with highly available **Read Replicas** across different availability zones.

---

## 📘 Problem Statement

You work for **XYZ Corporation**. Their application requires a reliable and scalable **SQL service** to store and retrieve data. As part of the migration plan to AWS, you're assigned to set up **AuroraDB** with enhanced availability.

---

## ✅ Tasks Performed

1. **Created an AuroraDB Engine based RDS Database** using AWS Console.
2. **Created 2 Read Replicas** in **different Availability Zones** for better fault tolerance and infrastructure availability.
