# AWS Lambda Project

## 📄 Problem Statement
You work for **XYZ Corporation**. The company is launching a new **web-based application**, but they want to avoid running servers 24/7. Instead, they are looking for a **serverless, AWS-managed solution** that only runs when triggered.

## ✅ Tasks To Be Performed
1. **Create a sample Lambda function** using Python.
2. **Set the Lambda Trigger as SQS** and send a message to test the invocation.

## 📌 Tools & Services Used
- **AWS Lambda** – for serverless function execution
- **Amazon SQS** – to trigger the Lambda function
- **AWS Console** – for deployment and testing
- **Python** – as the Lambda runtime

## 🧠 Learnings
- How to create and deploy a Lambda function.
- How to integrate Lambda with SQS to process messages.
- Hands-on with AWS serverless architecture.
