# AWS CloudFormation Assignment

## 📄 Problem Statement
You work for **XYZ Corporation**. Your team is asked to deploy similar architecture multiple times for testing, development, and production purposes. To ensure repeatability and automation, you are tasked with implementing **AWS CloudFormation**.

## ✅ Tasks To Be Performed
1. Use the template provided in **CloudFormation Task 1**.
2. Add **Notifications** to the CloudFormation stack using **Amazon SNS** so that you get email alerts for every step in the stack creation process.

## 📌 Tools & Services Used
- AWS CloudFormation
- Amazon SNS (Simple Notification Service)
- AWS Console

## 🧠 Learnings
- Writing and deploying infrastructure as code (IaC) using CloudFormation templates.
- Integrating SNS for real-time stack creation alerts.
- Automating and reusing infrastructure for different environments.
