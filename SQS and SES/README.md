# AWS SQS and SES Project

## 📄 Problem Statement
You work for **XYZ Corporation**. Your team is required to deploy similar architectures multiple times for testing, development, and production purposes. As part of the automation and notification system, you are tasked with implementing **Amazon SQS** and **Amazon SES**.

## ✅ Tasks To Be Performed
1. **Create a FIFO SQS queue** and test it by sending messages.
2. **Register your email address in SES** (Simple Email Service) and send a test email to yourself.

## 📌 Tools & Services Used
- Amazon SQS (Simple Queue Service)
- Amazon SES (Simple Email Service)
- AWS Console
- Email verification in SES

## 🧠 Learnings
- Understanding the working of FIFO queues in SQS.
- Setting up email verification and sending test emails via SES.
- Integrating AWS messaging services for production-ready architecture.
