# 🔐 AWS IAM Users, Groups, and Policies Assignment

This project demonstrates how to manage user access in AWS using **IAM (Identity and Access Management)**. The goal is to implement a secure and organized user management structure for **XYZ Corporation** using **IAM Users, Groups, and Policies**.

---

## 📘 Problem Statement

You are working for **XYZ Corporation**.  
To enhance the security and manageability of the AWS environment, you have been tasked with implementing a structure to easily **recognize and monitor users** using IAM.

---

## ✅ Tasks Performed

### 👤 IAM Users & Groups

1. Created **4 IAM Users**:
   - `Dev1`
   - `Dev2`
   - `Test1`
   - `Test2`

2. Created **2 IAM Groups**:
   - `Dev Team`
   - `Ops Team`

3. Added users to respective groups:
   - Added `Dev1` and `Dev2` to the **Dev Team**
   - Added `Dev1`, `Test1`, and `Test2` to the **Ops Team**

📥 [View Users & Groups PDF](https://github.com/Vaishnavi-Golhar/AWS-Projects/blob/main/IAM%20And%20CloudWatch%20Projects/IAM%20Users/IAM%20Users.pdf)

---

### 🔐 IAM Policies

1. Created **Policy 1** (for Dev Team):
   - Full access to **S3**
   - Permission to **create EC2 instances only**
   - Full access to **RDS**

2. Created **Policy 2** (for Ops Team):
   - Full access to **CloudWatch** and **Billing**
   - Permission to **only list EC2 and S3** resources

3. Attached **Policy 1** to the **Dev Team**  
4. Attached **Policy 2** to the **Ops Team**

📥 [View Policies PDF](https://github.com/Vaishnavi-Golhar/AWS-Projects/blob/main/IAM%20And%20CloudWatch%20Projects/IAM%20Policies/IAM%20Policies.pdf)
