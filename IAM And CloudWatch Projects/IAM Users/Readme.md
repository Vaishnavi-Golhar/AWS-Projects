# 🔐 AWS IAM Users and Groups Project

This project demonstrates how to manage user access in AWS using **IAM (Identity and Access Management)**. The goal is to implement a secure and organized user management structure for **XYZ Corporation**.

---

## 📘 Problem Statement

You are working for **XYZ Corporation**.  
To enhance the security and manageability of the AWS environment, you have been tasked with implementing a structure to easily **recognize and monitor users** using IAM.

---

## ✅ Tasks Performed

1. Created **4 IAM Users**:
   - `Dev1`
   - `Dev2`
   - `Test1`
   - `Test2`

2. Created **2 IAM Groups**:
   - `Dev Team`
   - `Ops Team`

3. Added users to respective groups:
   - Added `Dev1` and `Dev2` to the **Dev Team**
   - Added `Dev1`, `Test1`, and `Test2` to the **Ops Team**
