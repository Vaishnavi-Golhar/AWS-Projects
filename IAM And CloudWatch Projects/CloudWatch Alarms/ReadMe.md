# ⏰ AWS CloudWatch Alarms Project

This project demonstrates how to use **Amazon CloudWatch Alarms** to monitor billing and EC2 instance performance, ensuring real-time alerts for cost management and infrastructure performance.

---

## 📘 Problem Statement

You are working for **XYZ Corporation**.  
To enhance visibility into infrastructure health and cost, you have been asked to:

- Set up alarms that notify the user of any anomalies.
- Monitor machine behavior for performance and configuration issues.
- Control billing using alarms and notifications.

---

## ✅ Tasks Performed

1. **Created a Billing Alarm**:
   - Monitors **estimated charges** for the AWS account.
   - Triggers an alarm when the estimated charges exceed **$500**.

2. **Created a CPU Utilization Alarm**:
   - Monitors **CPU usage** of an EC2 instance.
   - Triggers when CPU utilization exceeds **65%**.
   - Configured an **SNS Topic** to notify users via email when the threshold is crossed.
