# 📊 AWS CloudWatch Dashboard Assignment

This project showcases how to create a **CloudWatch Dashboard** to monitor the performance of an **EC2 instance**, including **CPU Utilization** and **Network metrics**, ensuring the environment is observable and secure.

---

## 📘 Problem Statement

You are working for **XYZ Corporation**.  
To ensure the reliability and security of the AWS infrastructure, you’ve been asked to implement a monitoring solution to:

- Recognize and monitor different users.
- Track EC2 instance performance for errors or misconfigurations.
- Visualize real-time metrics using **Amazon CloudWatch Dashboards**.

---

## ✅ Tasks Performed

1. **Created a CloudWatch Dashboard**:
   - Added widget to monitor **CPU Utilization** of a specific EC2 instance.
   - Added widget to monitor **Network In/Out** metrics of the same instance.

2. **Configured Metrics**:
   - Chose the relevant EC2 instance from the list.
   - Selected metrics under the **EC2 → Per-Instance Metrics** namespace.

3. **Customized Dashboard Layout**:
   - Adjusted time ranges, refresh intervals, and layout for clarity.
   - Ensured visibility for future analysis and incident response.
