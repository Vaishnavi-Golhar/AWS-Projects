# 🎭 AWS IAM Roles Project

This project demonstrates how to securely delegate access to AWS services using **IAM Roles** for specific users within an organization.

---

## 📘 Problem Statement

You are working for **XYZ Corporation**.  
To maintain the security of the AWS account and its resources, you have been tasked with implementing a solution that allows controlled access to **VPC** and **DynamoDB**, while enabling monitoring of user activity.

---

## ✅ Tasks Performed

1. **Created an IAM Role** with:
   - Full access to **VPC**
   - Full access to **DynamoDB**

2. **Trusted Entities**:
   - The role was configured to allow only `user1` and `user2` (created in the IAM Users assignment) to assume it.

3. **Role Testing**:
   - Logged in as `user1`
   - Switched to the role successfully
   - Verified access to VPC and DynamoDB services
