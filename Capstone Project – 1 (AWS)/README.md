# 🚀 Capstone Project – 1: Deploying a Multi-Tier Website Using AWS EC2

## 📘 Description
Amazon Elastic Compute Cloud (**Amazon EC2**) provides scalable computing capacity in the AWS Cloud. This project involves migrating Company ABC’s existing infrastructure to AWS while ensuring **high availability**, **scalability**, and **performance** using **Auto Scaling** and **multi-tier architecture**.

---

## 🧩 Problem Statement
Company **ABC** wants to move their product to **AWS Cloud**. Their current setup includes:
- A **MySQL Database**
- A **PHP-based Website**

They require:
- High availability
- Auto Scaling enabled for the website to handle traffic spikes efficiently

---

## ✅ Tasks To Be Performed
1. Set up the MySQL Database on AWS (Amazon RDS or EC2-based).
2. Deploy the PHP-based website on Amazon EC2.
3. Configure a **Load Balancer** to distribute traffic.
4. Implement **Auto Scaling** to maintain high availability.
5. Ensure proper security group settings and networking.

---

## 🧰 Tools & Services Used
- **Amazon EC2**
- **Amazon RDS** (or MySQL on EC2)
- **Elastic Load Balancer**
- **Auto Scaling Group (ASG)**
- **Amazon VPC** (for network isolation and security)
- **Security Groups and NACLs**

---

## 🌐 Architecture Overview
- **Web Layer:** PHP Website hosted on EC2 with Auto Scaling and Load Balancing
- **Database Layer:** MySQL Database hosted on RDS/EC2
- **High Availability:** Achieved using Auto Scaling and ELB
- **Scalability:** Automatically adjusts EC2 instances based on traffic
