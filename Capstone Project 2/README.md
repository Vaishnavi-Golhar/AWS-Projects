# 🌐 Capstone Project – 2: Website Orchestration using AWS

## 🏢 Industry
**Internet & Web Hosting**

## 📌 Problem Statement
How can we orchestrate a PHP-based website with **higher availability**, **faster deployment**, and **Auto Scaling** capabilities?

## 💡 Project Overview
In this project, we aim to **orchestrate a high-availability PHP application** using **AWS Elastic Beanstalk** and an **external Amazon RDS** database. The goal is to ensure minimal downtime, seamless scaling, and flexibility for updates using blue/green deployment strategies.

---

## 🎯 Objectives
- Deploy a PHP application using **Elastic Beanstalk**.
- Decouple the database from the application by launching an **external RDS instance**.
- Enable **Auto Scaling** and **high availability** for the environment.
- Ensure seamless updates, testing, and deployment with minimal disruption.

---

## ✅ Tasks To Be Performed

1. **Launch a DB instance** using **Amazon RDS**.
2. **Create an Elastic Beanstalk environment** for the PHP application.
3. **Configure security**, including security groups and IAM roles.
4. Enable **Auto Scaling** and **monitoring** features.
5. Perform a **blue/green deployment** strategy without affecting the database.

---

## ⚙️ AWS Services Used
- **Amazon RDS** (MySQL/PostgreSQL)
- **AWS Elastic Beanstalk**
- **Amazon EC2**
- **Auto Scaling Groups (ASG)**
- **Elastic Load Balancer (ELB)**
- **Amazon CloudWatch**
- **IAM & Security Groups**
