# ⚖️ AWS Auto Scaling Group (ASG) and Elastic Load Balancer (ELB) Project

This project demonstrates how to set up **Auto Scaling Groups (ASG)** and **Elastic Load Balancers (ELB)** on AWS to manage traffic and resource scalability for an application. The implementation helps XYZ Corporation handle dynamic load efficiently and cost-effectively.

---

## 📘 Problem Statement

You work for **XYZ Corporation**, which previously relied on limited on-premise systems. As application demand grew, so did the need to continuously purchase new hardware.  
To reduce infrastructure costs and improve scalability, the company decided to **migrate to AWS**.

---

## ✅ Tasks Performed

1. **Auto Scaling Group Configuration**:
   - Automatically **launch compute instances** when CPU utilization exceeds **80%**
   - **Terminate instances** when CPU utilization drops below **60%**
   - Ensures optimal use of cloud resources based on demand

2. **Elastic Load Balancer Setup**:
   - Created an ELB to **distribute incoming traffic** evenly across compute resources
   - Improves availability and fault tolerance of the application

3. **Domain Name Routing**:
   - Configured **Route 53** to route application traffic to the load balancer using a **custom domain**
