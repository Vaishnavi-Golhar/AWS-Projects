# ☁️ AWS S3 Bucket Creation Project

This project demonstrates the use of **Amazon S3 (Simple Storage Service)** to store and manage application files. The objective is to provide a flexible and scalable storage solution for **XYZ Corporation**, allowing for public file sharing when required.

---

## 📘 Problem Statement

You work for **XYZ Corporation**. Their application needs a reliable storage solution to **store files** and **share them publicly** if needed. Your task is to implement **Amazon S3** as the storage backend.

---

## ✅ Tasks Performed

1. **Created an S3 Bucket** for file storage.
2. **Uploaded 5 different files** with various file extensions:
   - `.jpg`
   - `.pdf`
   - `.html`
   - `.txt`
   - `.docx`
3. Verified the successful upload and public accessibility settings (if required).
