# 🔄 AWS S3 Bucket Versioning Project

This project demonstrates how to enable **versioning** on an Amazon S3 bucket to keep multiple versions of objects. This helps **XYZ Corporation** to maintain backups and recover older versions of files if needed.

---

## 📘 Problem Statement

You work for **XYZ Corporation**. Their application requires a storage solution that can **store files** and **publicly share them**, while also maintaining **file version history**. Your task is to implement **Amazon S3 versioning** on a previously created bucket.

---

## ✅ Tasks Performed

1. **Enabled Versioning** on the S3 bucket created in the [S3 Bucket Creation Task](https://github.com/Vaishnavi-Golhar/AWS-Projects/tree/main/Simple%20Storage%20Service%20(S3)/S3%20Bucket%20Creation).
2. **Re-uploaded 2 existing files** to verify that S3 versioning is working.
3. **Verified version history** in the bucket and ensured previous versions were retained.
